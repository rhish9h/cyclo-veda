# Specs

Pre-implementation design documents. Everything here is written before code is written.

## Structure

- `roadmap/` — Feature backlog. Each file is a brief entry (title + description) capturing what needs to be built and when.
- `design/` — Full pre-implementation design docs. One subfolder per feature, written when the feature is ready to be built.
- `old/` — Archived specs for features that have been implemented or superseded.

After a feature is implemented, relevant technical documentation moves to `documentation/`.
