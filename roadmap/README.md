# Roadmap

Feature backlog organized by priority bucket. Each file is a brief entry (title + description) capturing the idea before detailed design begins.

When a feature is ready to be built, a full design spec is created in `../specs/design/`.

## Milestones (in order)

- `1-pre-dev-deployment-must-have/` — Deploy safely to the cloud for the developer's own use. Infrastructure security and hardening; URL not shared.
- `2-pre-public-deployment-must-have/` — Share with close friends. Same deployment, adds user-facing necessities and monitoring.
- `3-mvp-must-have/` — Open to general audience. Full feature set required for a minimum viable product.
- `4-wishlist/` — Nice-to-have ideas with no committed timeline.
